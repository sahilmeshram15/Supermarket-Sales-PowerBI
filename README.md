# 🛒 Supermarket Sales Dashboard – Power BI

## 📊 Project Overview

This project is an interactive Supermarket Sales Dashboard
created using Microsoft Power BI.

The dashboard provides insights into sales, profit, orders,
products, cities, customer types, payment methods, and gender.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📈 Key cards

- Total Sales: 287.48K
- Total Profit: 58K
- Total Orders: 380
- Total Quantity: 1K
- Profit Margin: 20.1%

## 📊 Dashboard Features

- Monthly Sales Analysis
- Sales by Product
- Sales by City
- Sales by Product Category
- Sales by Payment Method
- Sales by Customer Type
- Gender-wise Sales Analysis
- Interactive Filters

## 🔍 Key Insights

- May recorded the highest monthly sales.
- Floor Cleaner was the top-selling product.
- Mumbai recorded the highest city-wise sales.
- Household was the highest-performing product category.
- UPI was the most-used payment method by sales value.
